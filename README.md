# Rassegna Finanziaria

Sito statico pronto per GitHub e Cloudflare Pages.

## Pubblicazione

1. Caricare tutti i file nella radice del repository GitHub `rassegna-finanziaria`.
2. In Cloudflare Pages collegare il repository.
3. Framework preset: `None`.
4. Build command: lasciare vuoto.
5. Build output directory: `/` oppure `.` a seconda dell'interfaccia.

## Struttura

- `index.html`: ultima rassegna
- `archivio.html`: indice archivio
- `archivio/`: edizioni storiche
- `assets/`: CSS, JavaScript e logo

La pagina contiene dati dimostrativi e deve essere aggiornata prima dell'uso operativo.
